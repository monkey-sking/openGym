openGym video sync

The workout and the follow-along video pause and resume together.

Not connected

If the local relay is off
  1. In openGym, open Settings > Video sync and click Set up Mac helper.
  2. Open the downloaded app once. It installs itself for this user and stays in the menu bar.
  3. Return here and click Reconnect.

No Terminal, Node.js, account, or administrator password is needed. macOS may ask once to confirm opening the downloaded app.

Chrome extensions cannot start a Mac app by themselves, so the helper has to be opened once.

On iPhone, allow Local Network access and enter this Mac's Wi-Fi address under Workout > More > Video sync.
