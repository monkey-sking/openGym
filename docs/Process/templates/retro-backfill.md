# 复盘回填：<一句话问题标题>

> 每修完一个用户报的问题必须填。门禁「复盘回填」检查项会比对本文与源码改动的先后。
> 四选一：防止（做不出这个错误）/ 拦截（做出来但被机器挡住）/ 暴露（漏到用户但被看见）/ 没挡住。
> 答「没挡住」必须新增一条机制——否则下次还会发生。

- **日期**: YYYY-MM-DD
- **用户看到的现象**: （用户的原话/截图路径，不是代码现象）
- **真实根因**: （到 文件:行号；不许写「缓存问题」「偶发」这种归因）
- **为什么之前没发现**: （测试为什么绿、检查为什么漏）
- **被哪一层挡住**: 防止 / 拦截 / 暴露 / 没挡住
- **新增机制**: （没有就不许关闭这条复盘）
- **同类还有几处**: （grep 过什么、结果如何）
